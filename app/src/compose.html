Write it for me

  1. Type what you want, like “reply saying Friday works, many thanks”.
  2. Copy anything it should know, like the email you're answering. Steps 1 and 2 work in either order.
  3. Press Ctrl+Alt+W. Your instruction is replaced with the finished text.

Typo fixing never uses any of this and stays fully offline. Copied text is only used if you copied it in the last 15 minutes, and never if it looks like a password or a link.
