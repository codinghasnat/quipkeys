How it works

Four signals, one guess, made at every space.

Plain spell checkers compare letters. QuipKeys models how a fast typist actually misses, then weighs every possible reading of the sentence before changing a thing.

Your keyboard

A slip to a neighbouring key is far more likely than a key across the board. Every candidate is scored by where your finger probably was.

wamt → want

Your rhythm

Two keys pressed almost together are probably swapped. A pause before a key often means it went wrong. Timing is evidence too.

thsi → this

The whole sentence

A language model built from 1.4 billion words of Wikipedia scores the sentence as a whole, and can go back and fix earlier words.

Hellon ice → Hello nice

Your words

Press Backspace straight after a fix to undo it, and QuipKeys never changes that word again. Your names and jargon stay yours.

kubectl stays kubectl

Spell by sound

Spell it how it sounds. Get the word you meant.

Switch on Spell by sound and QuipKeys also reads words spelt by ear, then lets the sentence decide between sound-alikes. Built with dyslexic writers in mind, free, like everything here. Off by default, so ordinary typing isn't affected.

Privacy

A tool that sees your keyboard has to earn your trust.

Everything runs here

The dictionary and language model are built into the app. It works the same with no internet connection.

Nothing you type is kept

It looks at the last few words, in memory, and forgets them on Enter, a click or an app switch. Only words you choose to teach it are saved.

Nothing is sent anywhere

No account, no analytics, no tracking. QuipKeys never connects to the internet.

Read every line

The code is public, so anyone can check these promises. It stays out of password fields, terminals and code editors.

Get it

Windows and macOS. Free.

Build it from source with Rust. Ready-made downloads are coming.

# Windows
git clone https://github.com/codinghasnat/quipkeys
cd quipkeys\app && cargo build --release
target\release\quipkeys.exe

# macOS
git clone https://github.com/codinghasnat/quipkeys
cd quipkeys/app && sh macos/make-app.sh --install
